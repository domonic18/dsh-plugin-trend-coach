## 1. 背景与目标

趋势交易课程目前以录播视频为主，学员面临三个问题：不知道体系全貌与学习顺序、看完记不住、遇到疑问无处追问。本产品把课程视频从「只能看」变成「可问、可查、可溯源、可互动」的学习环境。

**产品目标**

1. 学员就趋势交易体系的任何问题提问，得到基于课程内容的回答，并能点回对应视频时间点。
2. 把录播课程系统化为「体系 → 模块 → 知识点 → 视频片段」的知识结构。
3. 学习过程中随时多模态提问（文字 / 语音 / 图片），回答带出处。
4. 提供仿 OpenMAIC 的 AI 互动课堂，把知识点讲清楚。
5. 具备对外运营所需的后台管理能力。

**交付形态**：学员本地 dsh 客户端 + 本插件，学员自带模型（D1/D8 已定）；云端只提供知识与内容服务，不承担推理。

**非目标（本期）**

- 不做实盘交易信号、荐股、组合管理。
- 不做课程售卖与支付闭环：本期免费内测，商业化后置（D7）。
- 不做 UGC 课程生产（学员不能投稿课程）。
- 平台不提供托管推理（无 Key 学员不在本期支持范围）。

## 3. 产品形态与部署（已定 D1：dsh 客户端 + 插件）

本期定位**对外公开发布的产品**，交付形态为「学员本地 dsh 客户端 + `dsh-plugin-trend-coach` 插件」，云端退化为知识与内容服务（BFF）。

```
学员电脑                                     云端（知识与内容服务）
┌────────────────────────────────┐          ┌──────────────────────┐
│ dsh 客户端（学员自己的模型 Key）    │  HTTPS  │ 账号与订阅            │
│  ┌──────────────────────────┐  │ ───────> │ 课程/知识点/文章       │
│  │ trend-coach 插件          │  │          │ 知识库与混合检索       │
│  │ Host 半：工具 + 服务       │  │ <─────── │ embedding 查询        │
│  │ Browser 半：课程页/播放器   │  │          │ 云点播加密播放        │
│  └──────────────────────────┘  │          │ 后台管理 + 埋点       │
│  本地 agent loop → 本地 LLM     │          │ 插件包分发            │
└────────────────────────────────┘          └──────────────────────┘
```

**职责边界**

| 端 | 负责 | 不负责 |
|---|---|---|
| 学员本地（dsh + 插件） | agent loop、LLM 推理、会话、课程 UI、播放器、语音转写（云端 ASR，D9） | 课程内容存储、检索、鉴权 |
| 云端 | 账号、课程与知识点、KB 索引与检索、embedding 查询、云点播加密播放与防盗链、后台、插件分发 | LLM 推理、agent 编排 |

**为什么这样切**：模型调用走 dsh 的 `ctx.llm`，路由到学员自己配置的 provider（DeepSeek 官方或 OpenAI/Anthropic 兼容端点），token 成本由学员承担；云端只承担视频带宽、embedding 查询与一次性内容生产成本。

**dsh 插件技术边界（调研结论，作为实现约束）**

1. 插件是 npm 包，可同时含 Host 半（Node）与 Browser 半（React），`package.json` 的 `dsh.client` 声明浏览器入口。
2. Host 半注册工具（`ctx.tools.register`）、技能（`ctx.skills`）、Cordis Service，并可直接发起 HTTPS 请求。
3. Host 服务经 Typert `@Remote` 暴露给 Browser，通过 `ctx.remote.<namespace>` 调用；**不为插件另起 HTTP 端口**。第三方插件需自行 `$mount` 并注意注入顺序（见 3.1）。
4. UI 通过 `ctx.slots.register/inject` 注入；右侧栏用 `ctx.sidebarRightTabs.register()` 注册 tab 类型，页面型 tab 用 `ctx.sidebarRight.openTab()` 打开（细节见 3.1）。
5. 安装：`dsh plugin add <pkg>`，装完重启；Host 半更新需重启，Browser 半支持热更新。
6. dsh Web UI 只绑 `127.0.0.1:3080`；官方桌面包覆盖 macOS Apple Silicon 与 Windows x64，无 Intel Mac / Linux 官包。
7. dsh 官方标注开发者预览、未经安全审计：插件必须最小权限，不注册 shell / 文件写入类工具。

### 3.1 可行性验证结论（UI / Remote spike，2026-10-31）

在 dsh 0.2.1-rc.5 上以本地 mock 知识库 + 1 小时测试视频完成端到端验证，结论作为 M2 实现依据。

**已验证能力**

| 能力 | 结论 |
|---|---|
| Browser → Host Remote | `ctx.remote.trendCoach.search()` / `getSegment()` 调用成功，结果可在右栏面板渲染 |
| 右栏 tab | 引导卡片、tab 打开、标题与 body 渲染正常 |
| tab 导航参数 | `openTab(kind, { params })` 传入的 `segmentId/startSec/endSec` 在 body 中经 `useTabInfo()` 读取，`revision` 可用于重复导航 |
| 引用点击 → 播放定位 | 点击回答中的 `seg-xxx` 代码块 → 查询片段 → 播放器 seek 到 920s；`https://trend-coach.local/...` 链接拦截路径 seek 到 1870s |
| 真实视频 seek | 服务端支持 HTTP Range 时，1 小时视频定位秒开（`readyState=4`），满足 seek 误差 ≤ 2s 的验收口径 |
| tarball 打包安装 | `npm pack` 产物经 `dsh plugin add` 安装到全新 profile 后：宿主组件运行中、客户端 bundle 加载并挂载 Remote、模型实际调用课程检索工具、引用链接点击后播放器定位到 1870s |
| 设备码授权闭环 | Host 发起设备码，面板展示 `userCode` / `verificationUri` 并轮询；批准后轮询返回 grant 并写入 dsh credentials；重启 dsh 后仍显示已授权 |
| 令牌过期自动刷新 | 服务端吊销 access token 后，下一次检索触发 401 → 用 refresh token 轮换 → 重试成功；旧 refresh token 复用被拒（401） |
| 设备绑定与退出 | 授权与业务请求绑定 `deviceId`，`x-device-id` 不匹配返回 403；退出登录删除本地 grant，后续检索提示未授权 |
| 未覆盖问题兜底 | 无召回时返回 `relatedKnowledgePoints`（仅标题），工具渲染与右栏面板均列出；回答明确「课程未覆盖」，不生成引用或时间点 |
| 片段区间高亮 | 播放器展示 `[startSec, endSec]` 高亮条与当前位置标记；seek 到起播秒、播至 `min(endSec, start+60)` 自动暂停 |
| 展示字段与回退 | 检索与片段详情返回 `courseTitle/chapterTitle/knowledgePointTitle`；工具渲染与面板按「课程/章节/知识点」展示，字段缺失时回退显示 ID，不影响引用 |
| 入参/响应边界 | query 1–500 字符、topK 1–20、courseId/segmentId 白名单；响应 ≤512KiB、片段文本 ≤4000 字符；非法数据整体失败 |
| 错误映射与日志脱敏 | 401/403/404/429/5xx/超时/网络/响应不合法映射为可读中文文案；Host 与 mock 日志不含 token、完整 query、userCode 或完整 deviceId |
| 提示注入防护与免责声明 | 云端标题/正文包裹在固定 `<course_segment_data>` 边界内，剥离控制字符并转义伪造边界；工具描述声明内容不可信；面板与播放器常驻「课程内容仅供学习，不构成投资建议。」 |

**平台硬约束（实现必须遵守）**

1. **Remote 注入顺序**：第三方插件的服务需自行 `ctx.remote.$mount()` 注册；`remote.<namespace>` 在 mount 成功后才存在。若把它写入插件静态 `inject`，插件激活会一直等待该服务而死锁。正确顺序是：`$mount` → 成功回调 → `ctx.inject(['remote.<namespace>'], scoped => …)`。
2. **右栏 tab 定义**：`sidebarRightTabs.register()` 的 `guide` 必须是数组（每个条目含 `id/order/title()`），传单对象会运行时报错；tab body 注册在 keyed slot `sidebar.right.pane.tab`，key 为 tab 定义的 `id`。
3. **聊天 Markdown 链接限制**：dsh 只把 `http(s)`/`mailto` 渲染为可点击 `<a>`；自定义 scheme（如 `dsh-resource://`）会被降级为纯文本。因此引用交互不能依赖自定义 scheme 链接。
4. **视频定位**：播放器所在的服务端必须支持 HTTP Range 请求，否则 seek 需要先下载整段视频，无法满足起播与定位指标。
5. **插件安装与 peer 版本**：新 profile 自带 `pnpm-workspace.yaml`，`dsh plugin add <pkg>` 转发给 pnpm 时会因 workspace-root 检查失败，需追加 `-w`。插件 peer 版本必须与 dsh 版本精确对齐（当前 `0.2.1-rc.5`）；沿用旧范围（如 `^0.0.1-rc.1`）会解析到旧版依赖链，把未公开发布的 `@deepseek-ai/dsh-type-meta` 拉入解析并导致 404。
6. **profile bundle 组成**：`dsh plugin add` 会自动把插件写入 `dsh.profile.bundles`；新 profile 仅含 `@deepseek-ai/dsh-base`，启用 Web UI 还需加入 `@deepseek-ai/dsh-web-app`，否则 CLI 不启动 web 服务。插件包不携带 `@deepseek-ai` 运行时依赖，由 dsh 宿主提供。
7. **credentials 服务依赖**：`@deepseek-ai/dsh-base` 包含 `dsh-credentials-local`（服务名 `credentials`），但插件激活时它未必已就绪；必须把 `credentials` 与 `tools` 一起写进静态 `inject`，否则 `ctx.get('credentials')` 为空、插件激活报错。

**引用交互实现决策**

- 主路径：回答中的 `segmentId` 以代码块形式呈现，客户端捕获点击后调用 `getSegment(segmentId)` 获取起止秒，再打开右侧栏播放器 tab 并 seek。该路径不依赖模型额外输出链接，已实测可用。
- 备选路径：工具结果附带 `https://trend-coach.local/segment/<segmentId>?t=&e=` 链接，客户端在 capture 阶段拦截。实测拦截可用，但模型不一定原样复述链接，因此不作为唯一方案。链接中的 `t/e` 仅兼容展示，起止秒一律以 `getSegment` 为准。
- 播放器为独立页面型 tab（`kind: trend-coach-player`），参数包含 `segmentId / title / startSec / endSec / src / watermark / error`；`src` 由播放会话接口下发的短时效签名 HLS 地址提供，mock 阶段为本地加密样片。
- 为支持历史回答中的 `segmentId` 随时点击，检索服务需提供按 `segmentId` 查询片段元数据的接口（见 §6）。

## 4. 功能需求

### F1 课程问答与视频溯源（P0）

学员以自然语言提问，本地 agent 基于云端检索结果回答，并给出可点击的视频出处。

**需求点**

1. 覆盖趋势交易体系的全部课程内容，回答以课程口径为准，不泛泛而谈。
2. 每条回答附带引用：课程 → 章节 → 知识点 → 视频时间点。
3. 点击引用跳转播放器并 seek 到对应时间，自动播放 30–60 秒片段，片段内高亮；播放全程走私有加密分发并叠加用户水印。
4. 课程未覆盖的问题明确回答「课程未覆盖」，并给出最近的相关知识点，禁止编造。
5. 多轮追问保持上下文，引用随轮次更新。
6. 引用由云端返回的 `segmentId` 解析，模型只选择片段与撰写解释，**不得自行生成时间点**。
7. 聊天中的引用以可点击的 `segmentId` 代码块呈现（不依赖自定义 scheme 链接）；点击后在右侧栏播放器 tab 内定位，交互实现见 3.1。

**验收标准**

- 引用命中率 ≥ 90%（人工抽检 100 条，`segmentId` 与回答结论相关）。
- 基准模型（DeepSeek 官方 API）下首 token P95 ≤ 3s，完整回答 P95 ≤ 10s；不达标时提示学员更换模型。
- 未覆盖问题的拒答率 100%（不臆造课程内容）。
- 点击引用后的跳转成功率 ≥ 99%，seek 误差 ≤ 2s。

### F2 知识体系化呈现（P0）

后台把录播视频加工为结构化课程内容；插件内按体系呈现知识点与对应视频。

**后台（课程制作）**

1. 视频上传、转写（带时间戳）、章节自动切分。
2. 从转写稿提炼知识点、核心要点，生成课程文章草稿（LLM 生成 + 人工编辑审核）。
3. 建立「知识点 ↔ 视频片段（起止时间）」映射。
4. 内容版本化：草稿 / 待审 / 已发布；发布后进入知识库索引。

**客户端（插件体系页）**

5. 一屏看清体系结构：模块、层级、学习路径与完成状态。
6. 每个知识点可查看要点文章、跳转视频片段、发起提问。
7. 学习进度上报云端（观看时长、已学知识点）。

**验收标准**

- 视频转写时间戳与音轨偏差 ≤ 3s（抽检 30 段）。
- 课程核心知识点结构完整（课程制作人员评审通过）。
- 插件体系页到视频片段跳转可用，路径长度 ≤ 3 次点击。
- 文章未审核不得发布、不得进入问答知识库。

### F3 学习场景即时提问（P0）

学员在观看课程/阅读知识点时随时唤起提问，支持多模态输入。

1. 便捷唤起：选中文本提问、悬浮按钮、快捷键（dsh 客户端内）。
2. 输入方式：文字、语音（云端 ASR，D9）、图片（复用 dsh 的视觉模型能力，截图/拍照识别）。
3. 自动携带上下文：当前课程、章节、视频时间点、选中文本。
4. 回答同样带引用，可一键跳回视频。
5. 支持连续追问，会话可保存。

**验收标准**

- 语音转写准确率 ≥ 90%（安静环境普通话，抽检 50 条）。
- 语音提问端到端首响 P95 ≤ 5s。
- 图片提问可识别讲义/截图中的文字与图表要素，回答引用正确率 ≥ 85%。
- 上下文自动携带无需用户手动选择（默认开启，可关闭）。

### F4 AI 互动课堂（P1，仿 OpenMAIC）

对标清华大学 THU-MAIC/OpenMAIC 的互动课堂交互，结合趋势交易内容落地。

**OpenMAIC 参考能力**：AI 教师 TTS 讲解 + 聚光灯/激光笔、协作白板实时画图推导、随堂测验（选择/简答，AI 即时评分反馈）、互动仿真、PBL 任务、课堂讨论/圆桌/自由问答（LangGraph 状态机编排）。

**本期范围（D4 已定：单师课堂）**

1. AI 教师基于已发布课程文章开讲，支持暂停/追问/跳章。讲解词使用浏览器 Web Speech API（调用操作系统本地语音），零服务端成本，不通过 shell 调用系统命令。
2. 白板 + K 线图表标注：讲解趋势结构、形态、买卖点时在图上逐步标注（插件本地渲染）。
3. 随堂测验：每个模块 3–5 题，题库在课程制作阶段一次性预生成，课堂内即时评分与讲解。
4. 课堂内自由提问（复用 F1 知识库与引用能力）。
5. 课堂结束生成学习小结与待复习知识点。

**明确后置**：多人圆桌/分组辩论、PBL 项目协作、互动仿真（一期不做）。

**验收标准**

- 单节课（20–30 分钟）可完整生成并回放，内容与课程文章一致。
- 白板/图表标注与讲解词同步，无明显错位。
- 随堂测验评分与解析可用，错题进入复习清单。
- 课堂内提问引用命中率 ≥ 90%。

### F5 后台管理（P0）

1. 注册与登录：手机号验证码为主账号，插件内使用设备码授权登录，登录态绑定设备（D5）。
2. 用户管理：用户列表、状态、学习数据、封禁/解封、角色与权限。
3. 模型配置：**仅用于内容生产**（文章生成、embedding、可选 ASR/TTS），多供应商、任务级模型绑定、连通性测试、密钥加密存储；学员推理不使用平台 Key。
4. 知识库管理：课程/文档上传、索引状态、重建索引、召回测试、内容上下架。
5. 课程内容管理：视频、章节、知识点、文章、发布流程（同 F2 后台）。
6. 运营看板：注册数、活跃、课程完成率、提问量、引用点击率、检索 QPS/延迟、embedding 成本、视频带宽。
7. 插件分发：版本发布、最低 dsh 版本、灰度与强制升级。

**验收标准**

- 权限分级生效：学员不可访问后台接口（401/403），越权测试全覆盖。
- 密钥不明文落库、不出现在日志与接口返回中。
- 索引重建可幂等重放，失败可见且可重试。
- 插件版本兼容矩阵通过（覆盖最低支持 dsh 版本）。

## 5. 内容与知识管线

```
录播视频
  → ASR 转写（带时间戳）
  → 章节切分
  → 知识点 / 要点提炼（LLM）
  → 课程文章草稿（人工审核）
  → 发布
  → 入库：文章 + 知识点 + 视频片段映射
  → 索引：embedding + 全文（云端）
  → 检索：混合召回（向量 + 全文 + RRF）
  → 返回候选片段（segmentId + 起止秒 + 知识点）
  → 本地 agent 选择片段并作答（学员自己的模型）
  → 插件 UI 解析 segmentId 跳转播放器
```

**关键要求**

- 转写、文章、映射三者必须共享同一 `知识点 ID`，保证回答可回到文章与视频。
- 视频片段映射粒度为秒；一章可拆多个知识点片段。
- 内容发布与索引发布分离，未审核内容不进入问答。
- 检索接口只下发 Top-K 片段与元数据，永不下发整库正文。

## 6. 知识库与检索（独立实现，借鉴 ai-invest 方法论）

**已定（D2）：不耦合。** 本产品自建知识库——不进 ai-invest 的库、不调它的服务、不共享代码仓库，只借鉴其已被验证的技术方案与调优经验。物理隔离天然成立，两个项目的演进互不传导。

**借鉴的设计（技术选型对齐）**

1. 存储与召回：PostgreSQL 单库，halfvec 向量 + pg_trgm 全文 + RRF 混合召回。向量负责语义同义表述，关键词负责术语、形态名、指标名的精确命中。
2. 方法论注入：确定性方法论基座与检索结果双层注入，不作为普通可召回文档混在语料里。
3. 分块策略：受 embedding 单条上限（约 3072 token / 2048 字符）约束，长课程文章按章节 / 知识点语义切块，禁止按固定字数硬切。
4. 可移植的小件：文本截断、RRF 融合、全文查询构造等**无状态纯函数**直接移植即可，不构成耦合。

**不复用的部分**：ai-invest 的 `file_metadata` 表结构、知识树、Celery 任务、FastAPI 服务、鉴权与用户体系——这些与其业务强绑定，搬过来就是把耦合换了个形式。

**代价与应对**：重复实现意味着同一个检索缺陷要修两处。应对是把重复面压缩到「纯函数 + 技术选型对齐」，检索质量各自由本产品的评估集把关，不追求两套实现逐行同步。

**检索服务化（云端）**

- 端点：`POST /v1/kb/search`，HTTPS + 账号鉴权 + 按用户限流。
- 请求：`query`、可选 `courseId` / `moduleId`、`topK`。
- 请求边界：`query` 去首尾空白后 1–500 字符；`topK` 取整并收敛到 1–20（默认 5）；`courseId` ≤64 字符且仅 `[A-Za-z0-9._-]`；`segmentId` 形如 `seg-...` 且 ≤80 字符。Host 在调用云端前统一校验，非法入参不发起请求。
- 响应边界：单次响应 ≤512KiB；单片段 `text` ≤4000 字符、`title` 与展示标题 ≤200 字符；`relatedKnowledgePoints` ≤5 条且仅含 `knowledgePointId/title`；越界或结构不合法整体失败，不静默截断。
- 响应 `segments[]`：`segmentId, courseId, chapterId, knowledgePointId, title, startSec, endSec, text, score`，以及展示用 `courseTitle, chapterTitle, knowledgePointTitle`（可选，缺失时客户端回退显示 ID）。
- 响应 `relatedKnowledgePoints[]`：`knowledgePointId, title`，用于「课程未覆盖」时给出最近知识点（F1.4）；只给标题，不得携带起止秒或片段正文，避免被误当引用。
- 片段详情：`GET /v1/kb/segments/{segmentId}`，返回单片段元数据、展示标题与起止秒，供客户端点击历史回答中的引用时定位；同样要求鉴权与限流。
- 播放会话：`POST /v1/playback/sessions`，请求 `segmentId`，返回 `sessionId / playlistUrl / expiresAt / watermark.label`。`playlistUrl` 为短时效签名 HLS，m3u8 内 key 与分片同样携带 token；浏览器不持 Bearer。`expiresAt` 至少覆盖一个片段播放窗口（60s），媒体源必须支持 CORS 与按需 Range。
- 查询 embedding 在云端计算（单次成本可忽略），全库正文不下发。

**授权服务（设备码）**

- `POST /v1/auth/device/code`：请求 `clientId / deviceId`，返回 `deviceCode / userCode / verificationUri / expiresIn / interval`。`deviceId` 由插件首次登录时随机生成，后续与该设备绑定。
- `POST /v1/auth/device/token`：请求 `deviceCode`，返回 `pending | authorized | expired`；`authorized` 时携带 grant：`accessToken / refreshToken / expiresAt / deviceId`。
- `POST /v1/auth/refresh`：请求 `refreshToken / deviceId`，返回同一结构的 grant，并轮换 access/refresh token（旧 refresh token 立即失效）；设备不匹配返回 403。
- 业务请求（检索、片段详情、播放会话）携带 `Authorization: Bearer <accessToken>` 与 `x-device-id`；缺失/过期 401，设备不匹配 403，客户端据此触发刷新、重新授权或提示设备异常。
- grant 只保存在 dsh credentials 的本地记录中（`$DSH_HOME/.credentials.yaml`，0600）；不写入插件配置、不写日志、不下发浏览器。M2 阶段可由 credential-ref 指向内部 token，M3 起统一走设备码。

**检索要求**

- 混合召回：向量语义 + 关键词精确（术语、形态名称、指标名）。
- 召回结果带来源元数据（课程、章节、知识点、视频时间点），供引用。
- 支持按课程/模块过滤。
- 召回评估集：≥ 100 条真实学员问题，Top-5 命中率 ≥ 90%。

## 7. 非功能需求

**性能**：云端检索 P95 ≤ 300ms；插件首屏 ≤ 2s；视频起播 ≤ 2s（CDN）。首 token 取决于学员本地模型，不作为云端指标。

**可用性**：云端知识/视频服务可用性 ≥ 99.5%；本地模型故障由 dsh 与学员配置决定，插件需给出可读的错误提示。

**安全**

- 插件最小权限：不注册 shell / 文件写入类工具；工具入参严格校验。
- 云端返回内容视为不可信数据，隔离在工具结果边界内，防提示注入。
- 视频分发：云点播私有加密 HLS（D3），播放地址短时效签名、绑定设备与并发数，禁止直链与下载。
- 内容版权：播放画面叠加用户 ID + 时间戳的动态移动水印，泄露可追溯到人；单账号设备数限制与异地登录告警。
- 防截屏边界：无法 100% 阻止系统截图/外接拍摄，目标定为「提高抓取成本 + 泄露可追溯」，不承诺绝对防截屏。
- 用户数据加密存储，敏感字段脱敏。
- 插件包签名与版本锁定，禁止加载未签名来源。

**合规**

- 投资相关内容必须附风险提示与免责声明，明确「课程内容不构成投资建议」，插件 UI 内常驻。
- 生成式 AI 服务合规（备案、内容审核）需在公测前确认。
- 用户隐私与个人信息保护（收集范围最小化、可注销）。

**成本**

- 云端成本 = 视频带宽 + embedding 查询 + 一次性内容生产（ASR / 文章生成 / 题库预生成）。
- 按用户设置检索配额与带宽告警；推理成本由学员承担（BYOK，平台不发兜底 Key）。

## 9. 风险与依赖

| 风险 | 影响 | 应对 |
|---|---|---|
| 客户端安装门槛 | 高：学员需先装 dsh（约 300MB，仅 macOS Apple Silicon / Windows x64），无 Intel Mac / Linux 官包 | 内测期图文引导；公测前交付一键安装包（D10）；一期定位技术型学员内测 |
| dsh 预览版未经安全审计 | 高：可在本地执行代码、加载第三方插件 | 插件最小权限、代码开源可审计；云端只暴露只读接口 + 限流 |
| 投资建议合规 | 高：可能触碰荐股/投顾边界 | 定位为「课程学习」；全站免责声明；回答不生成买卖建议；法务评审 |
| 授权范围不覆盖二次加工 | 高：转写、改写文章、入库检索可能超出授权 | 授权书须明确覆盖「转写 → 改写课程文章 → 入库检索」；授权文件到位前 M1 不开工 |
| 学员模型能力差异 | 中：回答质量与引用准确性波动 | 引用由 `segmentId` 保证；在基准模型下验收；低能力模型提示更换 |
| 插件 API 漂移 | 中：预览版规范变动导致插件失效 | 锁定 dsh 版本区间 + CI 兼容矩阵，不追 latest |
| 聊天引用交互受 dsh Markdown 限制 | 中：自定义 scheme 不可点，引用可能退化为纯文本 | 以可点击的 `segmentId` 代码块为主路径（3.1 已实测）；引用链接仅作备选 |
| 云端内容被爬 | 中：课程内容外流 | 只下发 Top-K 片段、鉴权限流、暗水印 |
| 视频带宽成本 | 中：长视频高频回看 | 签名 URL + CDN + 单用户配额与告警 |
| OpenMAIC license 冲突（MIT vs AGPL-3.0） | 中：若复用代码可能传染 | 只仿交互、不复用代码；若复用先以仓库 LICENSE 为准并法务确认 |
| ASR 时间戳精度不足 | 中：溯源跳转偏差 | 选带词级时间戳的 ASR，抽检验收 |
| 知识库双份实现 | 中-低：同一检索缺陷需修两处 | 只移植无状态纯函数、技术选型对齐；召回质量由各自评估集把关，不做逐行同步 |

## 10. 关键决策

| 编号 | 决策 | 结论 |
|---|---|---|
| D1 | 产品技术形态 | dsh 客户端 + 插件交付；云端只做知识与内容服务（第 3 章） |
| D2 | 知识库复用方式 | 不耦合：独立实现，只借鉴 ai-invest 的技术方案与调优经验（第 6 章） |
| D3 | 视频播放与溯源 | 云点播私有加密 HLS + 用户 ID/时间戳动态移动水印；签名防盗链 + 设备绑定；不承诺绝对防截屏 |
| D4 | 互动课堂一期范围 | 单师课堂：讲解 + 白板标注 + 随堂测验 + 课内问答 + 学习小结 |
| D5 | 注册登录方式 | 手机号验证码 + 插件设备码授权登录，登录态绑定设备 |
| D6 | 课程内容权属 | 已获授权方授权；授权书须覆盖转写、改写文章、入库检索等二次加工 |
| D7 | 商业化 | 本期免费内测，不做支付/订阅 |
| D8 | 模型托管方式 | 学员 BYOK：推理走学员自己配置的模型，平台不提供兜底 Key |
| D9 | 语音方案 | 云端 ASR + 操作系统本地 TTS（经浏览器 Web Speech API 调用，不执行系统命令） |
| D10 | 客户端分发 | 分阶段：内测期图文引导 + `dsh plugin add`；公测前出一键安装包（dsh + 预装插件 + 课程入口） |
